# 💰Sales-Case-Study
A project about analyzing the daily trading information for a large retail store, aggregated for the day

## 📌Project Overview
This project uses a simulated daily sales dataset for a single product to build core sales and margin metrics, measure how demand responds to promotional pricing, and surface additional insights through analysis and visuals.

## 📊Dataset
Daily records with:

-Date — day of trading
-Sales — total Rand value of sales
-Cost of Sales — total Rand value of cost of sales
-Quantity Sold — units sold

## 🎯Objectives
1.Daily sales price per unit
2.Average unit sales price
3.Daily % gross profit
4.Daily % gross profit per unit
5.Price Elasticity of Demand for 3 promotional periods, and whether the product performs better or worse on promotion
6.Other insights — visuals, reports, dashboards, KPIs
